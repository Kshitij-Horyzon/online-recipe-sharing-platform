# Online Recipe Sharing Platform Using Java

## Project Description

The Online Recipe Sharing Platform is a Java-based application that allows
users to share, discover, search, rate, and comment on recipes.

The system provides separate functionality for Users and Administrators.

## Main Features

### User
- Register/Login
- Manage profile
- Share recipes
- Discover recipes
- Search and filter recipes
- Rate recipes
- Comment on recipes

### Admin
- Manage users
- Manage recipes
- Approve/reject recipes
- Monitor user activity
- View recipe statistics
- Manage system settings
